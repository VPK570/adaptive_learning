# Project Instructions

## Local Skills

The following local skills are installed in `.agents/skills/`:

- **create-skill**: Guide for creating effective skills. To use this skill, manually read `.agents/skills/create-skill/SKILL.md` and its references, as it may not be available in the `activate_skill` tool yet.
- **repo-reviewer**: Deep, evidence-backed repository auditing and review for correctness, security, performance, and maintainability. Provides actionable diffs and verification artifacts. To use, manually read `.agents/skills/repo-reviewer/SKILL.md`.

## Development Workflow

- Use `create-skill` when extending the agent's capabilities with new specialized workflows or domain knowledge.
