## Editing

1. Open [excalidraw.com](https://excalidraw.com)
2. Click the folder icon (or Ctrl+O) → select `all-diagrams.excalidraw`
3. Edit, rearrange, or export as PNG/SVG/PDF
4. Save back to the same file

## Regeneration

The file was generated by `scripts/generate_excalidraw.py`. To regenerate:

```bash
python3 scripts/generate_excalidraw.py
```
